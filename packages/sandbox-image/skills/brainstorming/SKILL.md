---
name: brainstorming
description: Explore requirements and tradeoffs with the room before planning or implementation.
---

Use this skill when a user asks to brainstorm, shape a feature, or compare approaches before implementation.

Ask focused questions with the `ask_question` tool when the answer changes the plan. Prefer short option sets when the choice is bounded. Use `answerable_by: "decider"` by default so the session creator coordinates the room, unless the question is explicitly assigned to a participant.

Keep the outcome concrete:
- restate the decision or uncertainty
- identify the next implementation step
- avoid asking questions that do not affect the work
